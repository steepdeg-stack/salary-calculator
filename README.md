# Зарплатный калькулятор

Простое статическое веб-приложение для ежемесячного расчёта зарплаты 20–30 сотрудников.
Без сервера и базы данных: HTML + CSS + JavaScript, данные хранятся в браузере (localStorage).

## Как открыть

- **Онлайн:** https://steepdeg-stack.github.io/salary-calculator/
- **Локально:** скачать файлы и открыть `index.html` двойным кликом.

Работает на компьютере и на телефоне. На компьютере сотрудники показаны таблицей,
на телефоне — карточками.

## Как пользоваться

1. Выберите месяц и год сверху.
2. Нажмите **«Добавить сотрудника»** и раскройте строку сотрудника (стрелка слева или имя).
3. Заполните имя, должность, **тип расчёта** (менеджер или руководитель), дату выхода на работу,
   оклад и плановую зарплату с KPI. Полный KPI, норма рабочих дней и «Отработано» считаются автоматически.
   Норму можно переключить в режим **«Ввести вручную»** — например, для сменного графика.
   Кнопка **«Открыть календарь»** показывает рабочие дни, выходные, дни до выхода и отсутствия.
4. Заполните при необходимости премию, выслугу лет, штрафы и ручную корректировку
   (минус разрешён только в корректировке). Пустое поле считается нулём.
5. В блоке **«Выплаты»** первая выплата планируется на 1-е число (у менеджера по умолчанию 60 000 ₽),
   вторая — на 15-е число и равна остатку. Кнопка **«Выдано»** фиксирует фактическую сумму и дату.
6. Кнопка **«＋ Отсутствие»** добавляет отпуск, больничный или дни за свой счёт.
   Календарные дни и пропущенные рабочие дни (график 5/2) считаются автоматически,
   пропущенные дни можно поправить вручную — это нужно для сменных сотрудников.
   Отсутствие, переходящее из месяца в месяц, автоматически делится между месяцами.
7. **«Скопировать месяц»** переносит постоянные условия предыдущего месяца (оклад, план, норму).
   Премия, выслуга, штрафы, корректировка, обороты, комментарий и выплаты начинаются пустыми.
8. **«Экспорт CSV»** сохраняет расчёт для Excel, **«Резервная копия» / «Импорт копии»** — JSON-файл со всеми данными.

Данные сохраняются автоматически и остаются после обновления страницы.
Резервную копию стоит выгружать регулярно: данные хранятся только в этом браузере.

## Формулы

Внутренний упрощённый расчёт, НДФЛ и взносы не считаются.

Оклад начисляется полностью и не уменьшается из-за отсутствий.

```
Полный KPI       = max(Плановая зарплата с KPI − Оклад, 0)
Норма            = рабочие дни месяца по производственному календарю РФ
                   (при выходе в середине месяца — с даты выхода до конца месяца)
Отработано       = Норма − рабочие дни отпуска − рабочие дни больничного − дни за свой счёт
KPI за дни       = Полный KPI × Отработано ÷ Норма
Больничные       = Оклад ÷ 29,3 × календарные дни больничного
Дни за свой счёт = 0 ₽

Отпускные менеджера     = Оклад ÷ 29,3 × календарные дни отпуска
Отпускные руководителя  = 60 000 ₽ фиксированно, если в месяце есть отпуск

Начислено = Оклад + KPI за дни + Отпускные + Больничные
            + Премия + Выслуга лет − Штрафы + Ручная корректировка
Остаток   = Начислено − Всего выдано   (отрицательное значение показывается как переплата)
Прибыль   = Оборот выход − Оборот вход
```

Суммы округляются до копеек.

## Проверка расчётов

```
node tests/check.js
```

Скрипт проверяет производственный календарь, формулы менеджера и руководителя,
норму по дате выхода, премию, штрафы, выплаты и импорт старых резервных копий.

## Публикация через GitHub Pages

Если сайт ещё не открывается по ссылке выше:

1. Откройте https://github.com/steepdeg-stack/salary-calculator/settings/pages
2. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
3. Ветка — **main**, папка — **/ (root)**. Нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   https://steepdeg-stack.github.io/salary-calculator/

## Файлы

- `index.html` — разметка страницы;
- `styles.css` — оформление;
- `app.js` — расчёты, хранение, импорт и экспорт;
- `calendar.js` — производственный календарь РФ (праздники и переносы);
- `tests/check.js` — проверка формул.
