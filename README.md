# Зарплатный калькулятор

Простое статическое веб-приложение для ежемесячного расчёта зарплаты 20–30 сотрудников.
Без сервера и базы данных: HTML + CSS + JavaScript, данные хранятся в браузере (localStorage).

## Как открыть

- **Онлайн:** https://steepdeg-stack.github.io/salary-calculator/
- **Локально:** скачать файлы и открыть `index.html` двойным кликом.

Работает на компьютере и на телефоне. На компьютере сотрудники показаны таблицей,
на телефоне — карточками.

## Как пользоваться

1. Выберите месяц и год сверху.
2. Нажмите **«Добавить сотрудника»** и раскройте строку сотрудника (стрелка слева или имя).
3. Заполните имя, должность, оклад, плановую зарплату с KPI и норму рабочих дней или смен.
   KPI и «Отработано» считаются автоматически.
4. Кнопка **«＋ Отсутствие»** добавляет отпуск, больничный или дни за свой счёт.
   Календарные дни и пропущенные рабочие дни (график 5/2) считаются автоматически,
   пропущенные дни можно поправить вручную — это нужно для сменных сотрудников.
   Отсутствие, переходящее из месяца в месяц, автоматически делится между месяцами.
5. **«Скопировать месяц»** переносит данные предыдущего месяца в текущий.
6. **«Экспорт CSV»** сохраняет расчёт для Excel, **«Резервная копия» / «Импорт копии»** — JSON-файл со всеми данными.

Данные сохраняются автоматически и остаются после обновления страницы.
Резервную копию стоит выгружать регулярно: данные хранятся только в этом браузере.

## Формулы

Внутренний упрощённый расчёт, НДФЛ и взносы не считаются.

```
KPI                = Плановая зарплата − Оклад
Отработано         = Норма − рабочие дни отпуска − рабочие дни больничного − дни за свой счёт
Оклад за работу    = Оклад × Отработано ÷ Норма
KPI за работу      = KPI × Отработано ÷ Норма
Зарплата за работу = Плановая зарплата × Отработано ÷ Норма
Отпускные          = Оклад ÷ 29,3 × календарные дни отпуска
Больничные         = Оклад ÷ 29,3 × календарные дни больничного
Дни за свой счёт   = 0 ₽
Итого              = Зарплата за работу + Отпускные + Больничные + Корректировка
Прибыль            = Оборот выход − Оборот вход
```

Суммы округляются до копеек.

## Проверка расчётов

```
node tests/check.js
```

Скрипт проверяет примеры из технического задания (Алексей Ч. за июль и август 2026,
Артём Б. за август 2026) с точностью до копейки.

## Публикация через GitHub Pages

Если сайт ещё не открывается по ссылке выше:

1. Откройте https://github.com/steepdeg-stack/salary-calculator/settings/pages
2. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
3. Ветка — **main**, папка — **/ (root)**. Нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   https://steepdeg-stack.github.io/salary-calculator/

## Файлы

- `index.html` — разметка страницы;
- `styles.css` — оформление;
- `app.js` — расчёты, хранение, импорт и экспорт;
- `tests/check.js` — проверка формул.
